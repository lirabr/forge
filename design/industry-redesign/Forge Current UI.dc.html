WHAT'S MISSING
  • No icons anywhere — the tab bar, the set checkboxes and the modal close are all raw text or native controls.
  • No exercise imagery or muscle-group identity; every card in the library looks the same.
  • Everything is one surface at one elevation, so the active day, a logged set and a PR read at the same weight.
  • Native number inputs and a <table> for set logging — 22px tap targets, well under the 44px minimum.
  • No rest timer, no completion moment, no chart — the progress view is three numbers and two lists.
  • Top nav in a sticky bar; on mobile it collapses into a horizontally scrolling row.
