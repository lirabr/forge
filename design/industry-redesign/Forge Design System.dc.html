Performance-lab design system

The repo's ground and primary are kept — #0f1115 and #5b8def. What's added is a grammar: square corners, hairline frames with registration marks, condensed headings over Inter, Lucide at 1.5 stroke, and a tonal ramp so a PR, an active day and a logged set no longer read at the same weight.

01

Principles

Instrument, not poster

Numbers are the interface. Weights, reps and volume get the largest type on any screen; labels stay small and quiet.

Line, not fill

Cards and figures are drawn, not filled. One solid accent object per screen carries the primary action — everything else is hairline.

Square corners

0px radius by default, 2px where a control needs softening. Nothing is pill-shaped except the muscle tags.

Pattern before hue

One accent only. Muscle groups are told apart by hatch angle and ramp step, so adding a seventh group never needs a new color.

09

Motion

120MS · EASE-OUT

Taps, tab changes, stepper increments. Fast enough to feel mechanical.

220MS · CUBIC-BEZIER(.2,.8,.2,1)

Set rows collapsing, sheets rising, screen transitions.

1000MS · LINEAR

The rest ring only. One second per second — a timer must not ease.

NEVER

Bounce, confetti, spring overshoot. The PR moment is a plate that snaps in and holds.
